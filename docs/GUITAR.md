# 吉他模块

新增于作品集之后，顶部导航增加吉他入口。四段视频顺序为《偏爱》《她》《流行的云》《爱错》。使用原片3秒处封面，完整保留演奏、音轨及画面比例，转码为1280×720 H.264/AAC160kbps/faststart，兼容网页播放器。原视频未修改。

preload=none，不自动播放；访客点击加载。胶卷横向浏览支持按钮、触屏与键盘方向键；原生视频控件提供音量、进度、全屏。开始播放另一段时暂停前一段；模块离屏或页面进入后台时暂停音轨。

assets/guitar/film-rail.png为内置ImageGen生成的胶片齿孔纹理：正视、哑光暖黑胶片边缘、均匀米色齿孔、无字无标识。guitar.css使用中间条带重复，不修改原图。

验证：桌面1440×1000、手机390×844无横向溢出；四条字幕准确；下一格滚动；两段实际网页解码播放与互斥；四条视频206范围响应；无页面JavaScript错误。
