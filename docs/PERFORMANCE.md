# 加载性能优化（2026-11-17）

## 已实施

- 移除浏览器运行时 Tailwind CDN，改为22KB预编译site.css。保留tailwind.site.cjs和styles/utilities.css，可在安装项目依赖后执行npm run build:styles重新生成。
- 移除Google Fonts外部样式/字体请求。保留相同Noto字体，按页面静态文字子集化并本地托管；未知字符继续使用系统字体回退。两份可变WOFF2合计235,600字节，附OFL许可。
- 图片/纹理转为等比例WebP，原文件不变。15张使用中的图像总计10,073,401字节降为530,322字节；480px首屏照片另为12,950字节。背景光影1,667,017降为15,440字节。
- 首屏人物照片增加尺寸、响应式srcset及高优先级；下方图片lazy/async，减少解码和带宽竞争。
- Hero循环保持自动静音播放及原有时长。桌面960px/24fps/422,041字节，手机640px/24fps/210,447字节，原版本923,183字节。离屏暂停和手动暂停保留。
- 隐藏PDF/Tableau iframe在打开对应弹窗后才设置真实src；不再初始访问时请求第三方看板。
- 吉他封面接近可见区域才设置poster；原演奏视频仍点击后加载，声音/全屏/播放互斥不变。
- 移除两个外部占位图请求，以相同标签文字和灰底展示；不虚构新项目封面。
- 取消视频上方导航的高成本实时背景模糊，保留原有近不透明深色导航。
- Pages打包给CSS/JS自动附内容哈希查询参数，避免新部署后继续复用旧脚本样式。

## 验证与限制

优化前线上单次观察：首次内容绘制约2.87秒、DOMContentLoaded约3.60秒、load约5.23秒；该结果仅代表本环境网络和缓存条件，不能保证所有地区相同。初始访问确有隐藏看板、PDF、大图及外部字体请求。

本地验证：初始请求不含PDF/Tableau、Tailwind CDN、Google Fonts；进入弹窗会加载真实看板；吉他封面在进入模块后加载；桌面/手机静音自动循环、卡片弹窗、筛选、分页、导航及吉他播放通过。保持暖黑视觉与所有现有文字内容。

GitHub Pages在不同地区的基础连接速度仍取决于网络，应用资源优化不能消除托管节点的网络延迟。

## 清晰度优先修订

按用户最新要求撤销上一轮有损图像/背景优化：页面重新引用原始JPG图片、原始PNG光影及胶卷纹理、原始吉他JPG封面。Hero恢复优化前1152×720、30fps的background-loop-v2.mp4（保留此前已确认的循环剪辑）；所有设备均使用同一高清版本。上一轮1MB首轮传输量与相关加载耗时不再代表当前版本。

继续保留不损失素材画质的优化：样式预编译、本地原字体子集、图片/吉他封面按需加载、看板点击加载、资源版本缓存、离屏暂停。原视频、图片尺寸及界面布局不变。

## 首页入口与吉他缓冲（2026-11-17）

- 新打开和刷新页面清除入口锚点并回到首页；页内导航仍可跳转各模块。
- 接近吉他区域时，仅对当前视频设置 preload=auto；节省流量模式或2G仅请求 metadata。切换时暂停上一首，其他视频设置 preload=none；页面隐藏或离开模块时暂停。preload是浏览器提示，不能保证实际下载量或取消已开始的传输。
- 显示真实 buffered 区间对应的可播放秒数、播放/缓冲状态。视频和 source 加载失败均提供重新加载按钮。
- 本轮不修改任何视频、图片或背景素材，不转码、不降低分辨率和码率。
- 已验证桌面1440px、手机390px的入口/刷新、导航、当前视频预加载、播放互斥、失败重试和布局。本地测试不能代表中国大陆访问GitHub的网络质量。
- 国内网络加速尚未接入；用户目前没有云账号及已备案域名，后续需准备云存储/分发资源并做实际地区测试。
